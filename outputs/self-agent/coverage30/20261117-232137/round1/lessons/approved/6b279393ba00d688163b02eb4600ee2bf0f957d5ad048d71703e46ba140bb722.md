# Verify Product Request Before Confirming Order Changes

## When
A customer requests to add or change an item in their selection to a product that has not been retrieved from sources or catalog searches in the conversation.

## Do
Search catalog sources to verify product existence, specifications, price, and availability before confirming the item update.

## Otherwise
State that you need to check the product information first or express uncertainty regarding item availability.
