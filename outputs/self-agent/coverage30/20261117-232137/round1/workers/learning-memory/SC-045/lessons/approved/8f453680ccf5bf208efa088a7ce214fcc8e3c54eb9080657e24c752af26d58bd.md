# Avoid promising completed order details without verification

## When
A customer asks for a callback and requests not to repeat information, but required order details remain incomplete or unconfirmed

## Do
Confirm only the callback time scheduled and state that saved details will be reviewed, without claiming order details are fully saved or ready for immediate ordering

## Otherwise
State clearly that specific missing details may still need to be confirmed during the call
