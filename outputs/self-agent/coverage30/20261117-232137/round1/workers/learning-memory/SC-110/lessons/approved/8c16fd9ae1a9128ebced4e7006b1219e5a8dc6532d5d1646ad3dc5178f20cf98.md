# State Exact Voucher Rejection Reason

## When
A customer asks to apply a voucher code, and tool pricing results list the promo code under expired promotions rather than product-ineligible promotions.

## Do
State clearly that the voucher program has expired.

## Otherwise
State that information about the promo status is unverified.
