# State Inventory Result Correctly After Check

## When
A tool call has already checked inventory and returned stock availability during the current turn

## Do
Acknowledge the stock status using the completed tool result instead of claiming inventory still needs to be checked

## Otherwise
Express uncertainty about stock availability until the official source or tool provides the answer
