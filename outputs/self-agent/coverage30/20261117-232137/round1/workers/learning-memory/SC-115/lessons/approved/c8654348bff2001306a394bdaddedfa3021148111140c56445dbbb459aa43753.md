# Exclude Cancelled Items During Order Creation

## When
the customer explicitly asks to exclude or remove a cancelled item from the final order

## Do
verify the updated cart contents and create the order containing only the requested active items

## Otherwise
express uncertainty about the updated cart composition and ask the customer to clarify the items to include before proceeding
