# Verify Product Details Before Stating Them

## When
Responding to a customer about an order or item when the system tools or sources return no order details or product information

## Do
Ask the customer to clarify or provide the correct details without stating specific unverified product names, sizes, colors, or order IDs

## Otherwise
Express uncertainty about the missing details and state that the system currently lacks that information
