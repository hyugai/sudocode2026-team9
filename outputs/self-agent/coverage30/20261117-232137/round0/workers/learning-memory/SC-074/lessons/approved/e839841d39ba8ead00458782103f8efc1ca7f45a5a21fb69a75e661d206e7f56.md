# Express Uncertainty Without System Status Claims

## When
A customer asks for specific detail or past context that is missing from provided sources or tool results

## Do
State clearly that the information is unavailable in the provided data and express uncertainty without inventing specific system limitation details

## Otherwise
Do not claim that the system lacks specific confirmation records or functionality unless explicitly supported by sources
